# 拾光私人工作台 · 0.2.0

原生 HTML、CSS、JavaScript ESM，无第三方前端运行依赖。支持本地模式和私人云模式：`frontend/server.mjs` 保留原有本机工作台；`backend/server.mjs` 提供账号、资料同步、私有附件与 Hermes AI 后台。服务器部署说明见 `../deployment/README.md`。

## 启动

需要已安装 Node.js。无需运行 `npm install`。

在本目录任选一种方式启动：

```powershell
npm start
```

```powershell
node server.mjs
```

推荐双击本目录的 `start.cmd`：它会检查服务状态，必要时在独立后台进程中启动服务，确认可访问后自动打开浏览器；重复运行会复用已启动的服务。

访问地址：

<http://127.0.0.1:4173>

使用 `start.cmd` 启动后，可以关闭启动窗口。电脑重启后需再次双击启动；日志在本目录 `.runtime` 中。直接运行 `npm start` 或 `node server.mjs` 则需要保持对应终端打开，按 `Ctrl+C` 停止。

默认仅监听本机 `127.0.0.1:4173`，没有发布到公网。需要换本机端口时，可以在当前 PowerShell 窗口设置：

```powershell
$env:PORT = '4174'
node server.mjs
```

本地开发服务也读取 `HOST` 环境变量。本地服务没有身份验证；公网部署必须使用相邻 `backend/` 后端与 HTTPS 代理。

## 已实现的界面和操作

- 空间主页：亮色霓虹卡片、自由画布平移和缩放；长按卡片约半秒，轻弹浮起后拖动摆放，松手保存。短按进入空间有推进转场；拖右下角改大小、菜单换颜色，也可直接拖手柄。小屏默认卡片列表，可切换自由画布。
- 动态侧栏：电脑悬停展开、移开收起，可固定展开；手机使用抽屉导航和底部快捷入口。
- 自建工作区：自由空间、课程、学生会事务、个人项目模板，自定义名称、用途、颜色和图标。每个空间包含笔记、原文件、关联待办；支持归档与恢复，笔记编辑保留修订。
- 文件拖入：可从桌面拖到工作区卡片或空间内保存原件；课程总入口会收进 AI 草稿，供选择具体课程，手机可用文件选择按钮。
- AI 收件台：主页直接输入文字或添加文件，草稿和队列保存在本机。未连接模型时明确等待；可手动选择工作区归档原文，查看回执、撤回未修改内容，已经编辑过的记录保留。
- 课程空间：使用与主页相同的霓虹画布和长按拖动，课程布局独立保存并纳入备份；搜索、筛选、拖文件到指定课程、课程创建、资料上传与下载、TXT／图片／PDF 预览、笔记编辑、旧版修订记录、Markdown 导出及课程助教偏好。
- 内页卡片：课程笔记/资料、自建空间总览/笔记/文件/待办、全局待办与灵感均采用独立自由画布，支持长按轻弹后移动、改颜色和尺寸；每个内页的布局纳入完整备份。阅读和编辑保持独立卡片，六级、AI、回顾及设置页统一使用明确的彩色分区。
- 六级计划：目标设置、词汇卡片、原创阅读练习及本地判分、错题本、听力音频、写作／翻译草稿、学习时长记录和归入六级的资料。
- 收集箱：文字、链接、消息摘录、附件、分类、归档及转为待办。
- 备忘与待办：新增、编辑、完成、日期安排、分类、优先级、归档与恢复。
- 学习回顾：根据当前空间的实际记录统计完成事项、笔记和学习时长。
- 偏好与连接：个人资料、模型服务偏好、连接状态、完整备份导入导出、窗口冲突恢复副本、版本检查。
- 全局搜索：按 `Ctrl+K` 搜索自建工作区、课程、笔记、待办和碎片。

## 私人云模式

- 首次访问使用服务器初始化码、自选用户名和至少 12 字符的密码建立唯一账号。其他设备登录同一账号后共享工作区；会话使用 HttpOnly / Secure cookie。
- 修改自动同步，附件先上传再提交记录；约每 5 秒检查远端变化。未保存的编辑会阻止自动替换当前页面。冲突时保留本机恢复副本，不覆盖其他设备的新内容。
- 云缓存与本地模式的数据分开。旧数据需要先从本地“偏好与连接”导出完整备份，再登录云端导入。示例数据不上传。
- 在云端设置页填写 DeepSeek API 密钥，密钥只保存到服务器私有文件，不写入浏览器存储或工作区备份。服务器运维备份会包含该配置，应私密保存。
- AI 收件台会在服务器排队整理，关闭页面后仍继续。支持文字及 TXT、MD、CSV、可提取文字的 PDF、PPTX、DOCX，结果归档到已有空间、课程或待办，保留原文、原件和可撤销回执。扫描图片的 OCR 尚未接入。
- 尚无微信 / QQ 自动读消息、微信小程序或 Windows 原生安装包。

## 本地模式的数据范围

- 页面会适配电脑、手机、平板尺寸，但当前服务只允许本机访问，尚未实现四台设备同步。
- 个人记录使用浏览器 `localStorage`，文件使用 `IndexedDB`。数据不在 Node.js 服务器中，也没有上传到云端。
- 不同浏览器、浏览器用户、设备，以及不同源均各自隔离。`localhost` 与 `127.0.0.1`、不同端口和不同协议也属于不同源；切换后不会自动看到原来的数据。
- 示例内容与个人数据分开管理。示例只用于体验页面，不代表已经导入了你的真实课件或完成了真实 AI 整理。
- 本次升级兼容原来的 `lumi-workspace-v1` 数据，保留课程、学习记录和附件；增加工作区、AI 收件记录和画布字段，不清空原记录。完整备份也包含这些新增数据。已有布局经过手动调整时，导入只补充缺少的卡片。
- 单个附件上限为 40 MB；完整 JSON 备份上限为 512 MB。导出包含附件原件，缺失原件时会报错，不会把不完整备份提示为成功。导入只补充缺少的记录；已有文字保留，冲突的英语草稿另存到收集箱。
- 多窗口检测到另一窗口有更新时，会阻止旧记录覆盖，并把本窗口改动保留为恢复副本；可在“偏好与连接”导出恢复副本后再导入合并。
- 不要清除此站点的缓存和网站数据，否则本地记录、已保存文件可能丢失。浏览器本地存储不能替代备份，原始课件请另行保留；无痕模式也不适合长期保存资料。

## 接口与后续接入

开发服务只提供静态文件和两个只读端点：

| 路径 | 返回内容 |
| --- | --- |
| `/api/health` | 服务状态、版本、`backendConfigured: false` |
| `/version.json` | `0.2.0` 与“本地界面版”标记 |
| 其他 `/api` 路径 | HTTP 501，`backend_not_configured` |

本地开发服务仅支持 `GET`、`HEAD`，其他方法返回 HTTP 405；不提供目录枚举。私人云接口另见 `../backend/README.md`。

本地模式不调用模型、不进行云同步。只有云端账号的“模型连接”表单会通过 HTTPS 把密钥交给私人后端；不要把密钥粘贴到笔记、普通草稿或源码中。
