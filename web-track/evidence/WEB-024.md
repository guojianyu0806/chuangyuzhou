# WEB-024 · Web 静态资源压缩与缓存

2026-11-10。分支 codex/web-ai-topics，旧版对照 d8bdc3f。

Web 服务按浏览器支持的编码返回 Brotli、gzip 或原文。JS/CSS 按实际响应内容及编码生成 ETag，浏览器带匹配的 ETag 刷新时收到 304，复用本地副本。文件更新后可收到新内容。HTML、会话、工作区和私有附件仍采用 no-store。

在同一台机器上用 Edge 157.0.4341.42、1280×900、独立回环服务和同一组合成数据复测。旧版通过 d8bdc3f 的 server.mjs 副本复跑，仅调整本地测试导入路径。各版共 25 次首屏或刷新样本，表内是中位数，计时止于界面标记挂载后两帧。限速为模拟延迟 60 ms、下载约 12 Mbps，CPU 降速单独测量。

Edge 首访收到 111 个 Brotli 响应，JS/CSS 正文从 1,542,718 B 降到 450,177 B，少 70.8%。按 Resource Timing 含响应头估算的传输量从 1,576,018 B 降到 483,477 B。普通刷新收到 111 个真实 HTTP 304，JS/CSS 正文 0 B，浏览器估算传输量为 33,300 B，少 97.9%。计时记录没有页面异常。
