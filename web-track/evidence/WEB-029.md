# WEB-029 · 自由画布卡片字号适配

2026-11-11。当前分支 codex/web-ai-topics，源码基准 d34cb81。

主页自由画布的预览字号原先受宽高中较小一项限制，短卡规则还会固定字号。现在预览正文、预览标题、数字和卡片内主题标识都按卡片宽高计算字号。矮卡片保留字号上限和紧凑排版。便签仍按剩余高度截取正文，表格继续按可见空间控制行数。

刷新演示工作区后复核「导览展示提示」。在原 322×506 卡片和 63% 画布缩放下，正文从 14 px 增至 20.04 px，标题从 24 px 增至 32.78 px，主题名从 16 px 增至 19.58 px。预览文字和主题名均位于各自区域内。

隔离 Edge 通过 5 组验收，页面错误为 0。固定 70% 画布缩放，便签从 290×310 拉高到 290×520，再加宽到 465×520，正文计算字号依次为 15.45、19.86、22.48 px。标题、主题标识、清单和表格也随卡片尺寸调整。实测 220×220 卡片的控件和文字边界，以及刷新后尺寸恢复。

全量工程检查 936 项，933 通过、0 失败、3 项跳过。源码清单 324 项验证通过。完整报告与浏览器脚本位于本地忽略目录 web-track/.local/WEB-029。
