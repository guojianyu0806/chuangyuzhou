# WEB-038 · 主画布主题标签与收纳盒定位

2026-11-15。分支 `codex/web-ai-topics`，源码基准 `3f169b6`。

普通工作区的画布卡片读取已保存的归类，直接在卡片内显示主题名。AI 伙伴不参与归类，收纳盒成员继续由用户手动选择。

折叠盒保留统一大小，标题提供完整名称提示。画布工具栏的「找盒子」按完整名称列出盒子、可见成员数和折叠状态。选择后聚焦盒头，便于展开和操作。「适应全部卡片」按可见盒体和散放卡片的边界计算视角，窄屏允许低于 30%，保存和备份也支持该视角。

隔离 Edge 使用模拟模型建议走完归类、确认、返回画布和撤销。390 像素宽时，全览约为 10%，两个折叠盒和散放卡片均在裁剪边界内，刷新后仍显示完整。用键盘从目录定位远处的盒子后，拖柄宽约 36 像素，展开和再折叠后成员和原坐标一致。全量 949 项中 946 项通过、3 项跳过、0 项失败。源码清单 328 项校验通过。本轮未调用真实模型。
