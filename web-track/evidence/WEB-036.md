# WEB-036 · 重叠收纳盒拖放目标

2026-11-15。分支 `codex/web-ai-topics`，源码基准 `1edaa7f`。

拖动卡片时，浏览器按指针下可见的盒子表面判定目标，跳过正被拖动的卡片。盒子标题、可见盒身和盒内卡片均可作为放置目标。松手时使用同一个判定函数。盒身仅在拖卡期间参与命中检测，平时可从盒身空白处平移画布。

用隔离 Edge 复测 31% 缩放下的重叠场景。指针落在前方折叠盒「课程复习与小组项目准备清单」标题上，高亮、保存归属和刷新后的卡片都一致。后方「资料总览」的成员保持原样。额外验证拖到展开盒的可见空白处、拖出、移动盒子、切页和重新加载。原主题标签和收纳成员的原坐标核对一致。浏览器无页面错误及模型调用。记录位于本地忽略目录 `web-track/.local/WEB-036-overlap-fix`。
