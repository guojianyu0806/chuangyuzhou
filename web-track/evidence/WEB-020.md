# WEB-020 · 按主题查看与 AI 归类

2026-11-10。开发基线为独立 Web 仓库的 a533e9a，分支为 codex/web-ai-topics。

从工作台画布进入「按主题查看」，选择卡片后生成 AI 建议。审核页显示当前主题、建议和依据，允许手工修改或跳过。确认后按主题浏览，可以打开原空间、方块或模块并按进入来源返回。每次最多选择 24 张，模型输入仅包含所选卡片的编号、名称、类型和已有简介。

审核草稿与正式主题分开保存。页面切换与同标签页刷新可恢复草稿及任务编号。服务端只在确认时写入主题关系和批次回执，同时检查卡片是否仍存在于工作台、审核时的归属是否仍有效。重复确认按原批次查询回执。撤销逐张检查当前归属由哪一批写入，保留后续调整。主题关系随正式工作区备份，合并时保留当前归属及撤销标记。
