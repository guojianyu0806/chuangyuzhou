# WEB-034 · 自由画布手动收纳盒

2026-11-12。分支 `codex/web-ai-topics`，源码基准 `50c8633`。

收纳盒作为自由画布中的独立对象保存名称、坐标、展开状态和选定的卡片。拖动盒子把手会带着已展开的卡片一起移动。单张卡片可以拖入、跨盒移动或拖出，拖出时按落点摆放。盒子菜单支持批量选择，取消勾选或移除盒子时将卡片放回原位置。主题归属由既有主题功能维护。

隔离 Edge 通过 9 项验收，包含只收进指定的同主题卡片、拖动展开和折叠的盒子、刷新恢复、拖出落位、打开卡片、切换列表及菜单批量操作。AI 伙伴和未选卡片的位置比对一致，页面错误和模型请求均为 0。后端和备份测试覆盖旧备份兼容、同步校验和并发主题确认。

全量工程检查 944 项，941 通过，0 失败，3 项跳过。328 项源码清单校验通过。原始报告位于 `web-track/.local/WEB-034`。演示工作台核对到 17 张原有卡片和新建收纳盒入口。
