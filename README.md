# 创宇宙

让每个人搭建自己的工作台。用模块、空间和方块组织资料、日程与任务，由 AI 伙伴协助查询、提出方案，并在用户审核确认后执行。

## AI 创新应用挑战赛

创宇宙让用户在自由画布上摆放空间与方块，也能在内容积累后请 AI 提议主题。用户可以挑选卡片，修改或跳过建议，确认后再显示主题名，并在必要时撤销归类。收纳盒由用户决定装哪些卡片，移动、折叠盒子或调整主题时，仍能回到原来的内容。

### 10 分钟本机复现

1. 安装 Node.js ≥22.13，从本仓库根目录运行 `node yuzhou/start.mjs`，在浏览器打开 `http://127.0.0.1:4397/`。Windows 也可以运行仓库中的 `启动宇宙完整副本.cmd`。基础应用不需要安装 npm 依赖或构建。
2. 首次打开时，用本实例的 `yuzhou/.cu-runtime/data/setup-code.txt` 中的初始化口令创建自己的账号。隔离审阅可在启动前将 `CZB_YUZHOU_PORT` 设为 `4398`，将 `CZB_YUZHOU_DATA_DIR` 设为本仓库 `yuzhou/.cu-runtime/` 下尚未使用的专用目录，口令会生成在该目录。
3. 进入工作台，添加空间和方块，从首页进入「按主题查看」。手动归类和收纳无需模型配置。真实 AI 归类需在「偏好与连接」里配置自己的 DeepSeek 连接，再主动发起请求。口令、Key 与运行数据不随源码交付。

源码包用验收提交 `68b6af9` 标记版本，[公开源码提交 `1d0f75f`](https://github.com/guojianyu0806/chuangyuzhou/tree/1d0f75fb37eb4faac15a634bad51c3a8dbb1420a/yuzhou) 的应用文件与之逐字节一致。自动回归共 929 项，926 通过、0 失败、3 项跳过。独立解压包已验证启动、资源缓存和主题归类的审核、确认、刷新、撤销流程。源码包的合成演示入口为 `node tools/review-demo.mjs`，使用本机模拟回复。
