# 创宇宙约4分钟演示脚本草案 v1

内部录制准备稿，不是已录视频。以下时间是剪辑规划；模型响应和操作耗时必须据实际录制调整。尚无真实AI调用结果，不能把预设回复录成真实AI。可先做标注“工程演练”的排练，正式主线待专用模型验收后录制。

## 录制前

- 使用独立演示实例和合成资料，画面不出现初始化口令、账号、Key、个人路径或身份信息。
- 记录代码、模型、prompt、任务和素材版本；开始前恢复同一合成初始状态，不使用真实用户实例试错。
- 准备项目名“读书分享计划”。合成资料原文：`读书分享会安排在2026年10月15日15:00至16:00，请准备两页要点。` 日期是固定演示材料，不称为真实活动。
- 完整差异/引文展示、偏好闭环、备份恢复和连接测试为本轮补齐项，**实施中，待最新验收**。尚未通过的入口不能写成录制已成功；本脚本不要求把全部功能塞进4分钟。

## 剪辑与验收

等待若加速或省略，注明“等待过程加速/缩短”，保留原始录屏和实际时间记录。演示中失败可简短说明，完整失败记录另存；不要只靠旁白声称事务、撤销或来源已经验证。
