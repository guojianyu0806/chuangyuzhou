# 创宇宙 · 传智杯开发版 v0.3.0

本版本于2026-10-08从创宇宙v0.2.1的已核验源码包建立独立副本，保留可组合工作台的定位和原界面。既有功能属于复用基线，本赛道新增改动和验证记录见上一级 `docs/实施状态.md` 与 `evidence/dev/DEV-001.md`。原自用宇宙、原创宇宙、历史发布包和运行数据未改动。

这是本地开发版本，尚未完成真实模型效果、真人试用、跨设备复现与参赛资格核实，不能据此宣称已经满足全部比赛要求。

## 打开这个副本

使用Node.js22.13或以上，本机验证25.7.0，无需npm安装。

双击上一级目录“启动传智杯工作台.cmd”，或在本目录运行：

```powershell
node start.mjs
```

本版本默认地址：http://127.0.0.1:4395 。启动前可在上一级目录运行 `node scripts/preflight.mjs`，检查Node版本、SQLite支持、入口和端口。端口占用时先确认已有进程，或运行 `node start.mjs --port 4396`；不要终止不明程序。

第一次打开时，自行从**本版本** `.cu-runtime/data/setup-code.txt` 复制初始化口令，在网页建立至少10字符的独立密码。口令和专用模型Key不要发到对话。账号、工作空间和模型配置只保存到本版本 .cu-runtime/data。

默认只监听127.0.0.1，允许 --port 选择4380至4399的空闲端口。Cookie名称为czb_workbench_session，布局缓存使用czb_workbench:前缀；不读取原工作台浏览器数据库。不要在相同主机同时运行多个比赛开发实例，以免同名Cookie互相替换。停止服务可在启动终端按Ctrl+C。

本项目不使用 `.env` 导入模型配置。独立Key由用户在本实例“设置”页面填写，不应写进源码、Git、截图或聊天。保存Key不调用模型；连接测试和AI任务可能计费，首次实测前须明确调用预算。

## 本轮新增：连续修订未保存方案

第一轮生成方案后，可继续输入修改要求或回答澄清问题。服务端保存话题上下文；界面显示当前在修订未保存方案。每次返回完整替代方案，点击确认前不写入工作台内容。修订失败保留原方案和输入。

“新话题”会结束当前未执行方案；确认、取消、空间版本变化或话题过期后不能继续沿用。话题上限8轮、有效期30分钟，从首轮开始计时。历史中的有效待核对方案可以重新打开继续修改。服务端拒绝客户端自行伪造的历史。

这些是工程约束与交互能力。离线测试使用合成模型输出，只验证流程，不证明真实模型一定理解追问或引用正确。

## 改造基础与功能

原页面风格、CSS、图标和canvas.js沿用既有成果；当前页面入口为 `frontend/index.html` 与 `frontend/sandbox/app.js`，后端为 `src/server.mjs`。本导入包只保留实际页面依赖与拒绝运行旧私人服务的兼容入口，不包含全部个人业务实现。首页空间卡片支持画布排列、缩放、拖动与尺寸交互；模块修改通过领域接口保存。

平台支持空白、学习、个人项目起始结构和普通上班族示例，五类模块为文字、列表、看板、日历和资料。列表、看板与日历可绑定同一集合，字段和选项使用稳定ID；修改一条记录后各视图同步。所有起始模板、结构导入和完整备份恢复先生成手动草稿，确认后才保存，空白空间可直接创建。

普通上班族示例包含月度工作与会议、部门活动筹备、生活与个人安排三页，初始为15个模块、3个共享集合、20条虚构记录和6份资料。日期从上海时区创建当天安排，包含工作报告、会议纪要、活动采购、购物与运动等事务，用户可自由删改。首页提供页面快捷入口及当前记录摘要；原首页画布位置保留。示例已建立或归档时打开/恢复原工作区，不重复创建；整体撤销后可以重新添加。资料仅为虚构范例，不表示真实通知、预订、账单或工作日安排。

比赛副本初始为空，不继承旧实例中的示例数据。首次使用可在模板入口预览并确认添加“普通上班族示例”，其中内容全部为虚构数据。

AI伙伴读取当前空间、选中对象和明确提供的偏好，只提出受限动作方案。核对面板可展开字段前后值、资料引文、保存全文及完整原始差异。确认执行需要状态版本一致；历史可筛选、重开待核对方案、查看回执和撤销，存在后续冲突或依赖时会拒绝撤销。引文和来源hash核对只检查可追溯性，仍需人工检查事实语义。

设置页填写此副本专用DeepSeek Key。保存配置不会调用模型；“测试已保存的连接”才发送一次小请求，可能产生少量费用，不发送空间内容。保存、连接检查和真实AI任务效果分别记录；型号或Key变化会清除旧检查结果。Key不进入页面状态、修改历史或数据导出。

完整备份保留空间、模块、记录及资料内容，不含账号、会话、Key和修改历史。恢复时选择一个源空间，先核对草稿，确认后保存为新ID副本，原空间保留；不能用来迁移原账号或把整个实例回滚。文件上限16 MiB，恢复后的全部状态上限8 MiB。AI不能自行生成备份恢复动作。

首页纸卡的平移、缩放及展示排列属于本副本浏览器的显示偏好；它不是工作空间内容修改或跨设备同步。模块布局依然受领域网格与碰撞校验约束。原个人课程、六级、账本等专用业务源码已备份，但不自动宣称它们已经转换为通用平台模板。

## 来源备份与运行边界

本次导入出处与ZIP校验见上一级 `evidence/provenance/base-import.json`；本仓库的基线提交保存导入时状态。旧宇宙备份及旧赛事文档不随本比赛副本自动扩展为新功能或新证据。

frontend兼容启动器委托本目录安全入口；backend服务器和CLI拒绝作为私人云入口执行。这两个兼容文件用于隔离测试，不含原私人服务器实现。原4173/4180服务、环境数据目录、Hermes与部署工具不会由本版本启动。

`SOURCES.md`、`TASKS.md`、`docs/`、`evaluation/` 中随包导入的v0.2.1资料是历史资料，可能包含旧路径、旧赛事格式或尚未完成的计划。本比赛最新进展以上一级README、AGENTS及实施状态为准。历史日期和旧报告不改写成本次结果。

## 验证与源码包

运行 `node --test tests/*.test.mjs evaluation/*.test.mjs` 使用Node内建测试和本版本内合成数据，不安装依赖或消费API。浏览器验收单独使用新临时profile和合成资料，旧复制的frontend/tests不直接执行到4173。

当前目录的 `SOURCE-HASHES.json` 是导入v0.2.1时的原始清单，`verify-source.mjs` 仅用于核对该基线。开发改动后对本目录运行会报告差异，这是预期现象。当前改动由Git diff与测试留痕；后续正式打包须为实际交付内容重新生成清单，不能使用旧哈希宣称新版本校验通过。
