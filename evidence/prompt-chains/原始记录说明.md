## 保留与排除

- 原文内的浏览器上下文包装、图片文件引用保留；这些包装不是用户指令。没有重新导出用户图片的像素，不能称为含全部附件的原生日志备份。相应实现效果可查历史工程截图。
- 不收录内部推理、系统/开发者消息、压缩摘要、子任务内部消息或工具执行正文。公开澄清问题是唯一保留参数正文的工具，因为问题及选项本身显示给用户。代码修改由真实 Git diff 和阶段证据补充。
- 密钥提供阶段不在选取范围内；提取器仍检查常见凭据模式并以 `[REDACTED_SECRET]` 替换。本次 104 条中替换次数为 0，不表示整份原日志没有秘密。原日志不可直接公开上传。
- 原始文字中的“示例”“合成”“失败”等历史表述必须保留。产品界面整理不会追溯改写开发证据，也不会把合成结果变为真人使用记录。
- 旧 `evidence/dev/raw/` 摘录继续原样保留；这里新增双方对话，补充而非替代原材料。

## 校验方式

每条公开记录保存原 JSONL 行的 SHA-256、原文本 SHA-256、导出文本 SHA-256和脱敏次数；清单保存文件哈希及固定历史前缀哈希。这些用于发现改变并与原日志对照，不是第三方时间戳或来源公证。

在仓库根目录执行便携校验（不需要原始私密日志）：

```powershell
python evidence/prompt-chains/archive_dialogues.py verify
```

作者本机可在相同命令后提供原始会话 JSONL 的完整路径，以核验前缀、逐条文本、记录哈希、选取范围及排除计数。脚本只读取源文件；`export` 遇到已有输出会拒绝覆盖。原始文件路径不作为评委复现程序的依赖。

历史测试数字只归属于当时的版本与验证范围。三条专业说明会把人的目标与约束、AI 提出的设计、AI 自查及真实模型失败分别说明；不补写当时不存在的人工修复指令。
