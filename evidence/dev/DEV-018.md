# DEV-018：梦境轻量提速与主动唤起衔接

日期：2026-10-13。用户原始表达见 `raw/DEV-018-user.txt`。

## 需求与方案

用户认可当前梦境的表现形式，希望流动稍快，并改善右下角主动唤起灵感时的不流畅感。保留现有配色、独立随机记录池、曲线路径及阅读保护，仅调整运动节奏与按钮触发的过渡。

代码核查发现：原主动唤起在空间不足时立即移除一条旧念头，再用跳过入场的方式显示新念头，且每次点击重置自动计时器。该逻辑可造成视觉跳变；尚不能据此断言设备存在性能瓶颈。

AI建议将相同路径的漂移速度提高约20%，周期由18—28秒缩短为15—约23.3秒；自动加入间隔和柔和明暗变化保持。按钮触发一次有反馈的渐隐/浮入过渡，重复点击合并，其他条目的DOM和运动进度保持。正常阅读、暂停、后台及减少动态效果边界继续有效。

## 范围与验收计划

仅直接修改本比赛 `yuzhou/` 源码复制件及本轮记录，旧源码由Git保留，原项目及旧成品不覆盖。独立合成实例检查满场过渡、连续点击、暂停中主动操作、搜索/尺寸变化/卸载清理，以及新速度与路径避让；不读取正式账号内容或调用模型。

## 实施与实际迭代

- `dream-motion.js`将相同路径的运动时长除以1.2，18—28秒改为15—约23.3秒。自动加入间隔、随机记录池、路径避让与星点呼吸频率保持。
- `dream.js`增加单请求过渡：正常替换先420毫秒离场，再680毫秒入场；空位直接入场。忙碌期间合并连续点击，按钮文字与焦点保留，通过轻微底色和光晕反馈；邻居的DOM与运动对象不重建，自动截止时间不因点击重置。
- 复核补齐已有自然离场的情形：接续其原1100毫秒动画，不重新开始，也不另删一条。两条记录的池即使随机抽回原记录，仍能正确结束忙碌状态。
- 显式暂停下允许这一回主动过渡，其他运动不恢复；弹层、后台、离屏和当前条目阅读同时冻结CSS与后备计时器。减少动态效果则直接完成。搜索、有效尺寸变化与卸载清理请求，旧动画事件迟到不会再次替换。
- 子代理只负责梦境控制器与挂载测试，另一代理独立只读审查。主代理负责速度、CSS和浏览器验证。审查建议的后备计时器/迟到事件竞态已补入测试，无阻断发现。
