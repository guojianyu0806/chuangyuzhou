# DEV-018：梦境轻量提速与主动唤起衔接

日期：2026-10-13。用户原始表达见 `raw/DEV-018-user.txt`。

## 需求与方案

用户认可当前梦境的表现形式，希望流动稍快，并改善右下角主动唤起灵感时的不流畅感。保留现有配色、独立随机记录池、曲线路径及阅读保护，仅调整运动节奏与按钮触发的过渡。

代码核查发现：原主动唤起在空间不足时立即移除一条旧念头，再用跳过入场的方式显示新念头，且每次点击重置自动计时器。该逻辑可造成视觉跳变；尚不能据此断言设备存在性能瓶颈。

AI建议将相同路径的漂移速度提高约20%，周期由18—28秒缩短为15—约23.3秒；自动加入间隔和柔和明暗变化保持。按钮触发一次有反馈的渐隐/浮入过渡，重复点击合并，其他条目的DOM和运动进度保持。正常阅读、暂停、后台及减少动态效果边界继续有效。

## 范围与验收计划

仅直接修改本比赛 `yuzhou/` 源码复制件及本轮记录，旧源码由Git保留，原项目及旧成品不覆盖。独立合成实例检查满场过渡、连续点击、暂停中主动操作、搜索/尺寸变化/卸载清理，以及新速度与路径避让；不读取正式账号内容或调用模型。测试与实际浏览器结果随后补充。
