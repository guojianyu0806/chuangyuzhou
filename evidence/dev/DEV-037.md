# DEV-037 · 真实课程与课表关联、比赛筹备资料

2026-10-18。用户授权把此前确认的真实课程加入课程空间，课表直达对应资料与笔记、保留原内容，并补充比赛区资料。只修改比赛复制件；正式业务仅通过正常登录 UI 操作，原项目和旧交付保留。私人课表与备份仅保存在忽略的 .cu-runtime，不进入 Git。

实施：可预览的课表转课程；同一课程多个时段共用稳定 courseId，复用唯一匹配的已有课程，重复执行不重复新建；不把个人安排笔记伪造成课堂记录或课件。课表直达课程，单独保留安排编辑；课程页可回看关联时段。比赛补充当前作品筹备任务与个人计划，不编造其他比赛报名、经历或官方截止日。验证与实际结果随后追加。
