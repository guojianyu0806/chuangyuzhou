# DEV-022：工作区迎接首页与悬浮模块

日期：2026-10-13。原始需求见`raw/DEV-022-user.txt`。

## 需求与设计计划

用户希望每次打开软件时先看到一个工作区入口，以Lightspark首页的中央留白、周围悬浮卡片及鼠标响应为视觉参考；点击中央进入按钮后，才进入已有自由画布。参考地址：https://www.lightspark.com/?ref=land-book.com 。正常浏览器已观察首屏：明亮底色、中央标题与按钮、大小错落的彩色卡片，卡片内部另有位移层。首次网页文本获取失败，浏览器完整状态读取多次超时，最终用浏览器截图和局部DOM观察完成参考核对；不据此声称测量了参考站全部动效参数。

本轮只在比赛`yuzhou/`增加迎接视图。正常鉴权后显示当前工作区名称与本人标识，周围内容来自当前工作台已启用模块、未归档空间和自定义方块的标题、颜色与聚合数量。保留原画布、侧栏配置、账号和记录，不另造示例/个人工作区划分。入口不加载附件或小程序，不发送模型请求。显式业务深链接继续可用。

视觉选择：纸白`#F8F9FB`底、墨色`#242137`正文、紫色`#7851D9`操作强调，并保留画布蓝`#9DC5FF`、青`#63E6DC`与粉`#FF9CCE`等模块色。中文标题采用已有系统中文字体的紧凑大字重，正文系统无衬线，极少量英文产品标识使用字距处理。构图为中央工作区入口、外围不规则模块群；识别点是工作台里的业务图形被做成悬浮小物件。将参考站的金融产品图像替换为课程、灵感、待办、AI等本项目图形，避免复制品牌资产或金融文案。

动效分层：卡片自然起伏与倾斜独立于鼠标追随；鼠标移动带来不同深度的错位和轻微避让，离开后缓和归位。中央按钮保持稳定可点。暂停按钮、系统减少动态效果、后台/离屏停止与离开清理均纳入验证，移动端以稳定入口和轻量装饰为主。

计划验收：当前账号入口到画布、新账号到搭建、返回入口、重新打开与深链；真实数据标题/颜色及隐藏归档边界；鼠标位移、自然悬浮、暂停/减少动态效果和清理；桌面及窄屏。全部使用合成账号，不读取正式凭据或私人数据库。计划不写成验收结果。
