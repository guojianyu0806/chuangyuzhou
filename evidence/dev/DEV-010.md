# DEV-010：侧栏宽度切换的弹性过渡

日期：2026-10-09。根据原始对话整理；需求原文见`raw/DEV-010-user.txt`。

用户要求侧边栏双击切换宽度时具有弹性伸缩动画。保留现有宽度语义：导航双击切换收起/展开，拖柄双击恢复默认宽度，拖动仍可连续选择宽度。

实施方案：以同一个宽度值同步驱动侧栏和正文，使用约360毫秒的轻回弹；拖动立即接管当前视觉宽度，动效不反复写入偏好或业务状态。重复切换可从当前位置续接，视口变小、控制器销毁或减少动态效果开启时终止动效并落到有效宽度。只修改本比赛`yuzhou/`复制件。

验证计划：离散切换与拖柄复位、动画中再次切换/拖动、最终宽度与保存次数、边界范围及减少动态效果；复用既有侧栏与导航回归。浏览器采用4398合成账号，不读取正式私人数据。

## 实施与验证结果

- 以requestAnimationFrame更新共享`--rail-width`，360毫秒阻尼回弹，同步改变侧栏与正文占位；始终限制在80与动态最大宽度之间。导航双击、收起/展开按钮、Enter/Home/End以及边界双击复位均接入。普通方向键微调和指针拖动仍即时反馈。
- 中途切换从当前视觉宽度续接，开始拖动立即停止动效；普通页面同步不会抢跑当前相同目标。保存回调有重入保护，动画帧不写偏好、不写业务数据。视口变化、窗口失焦、销毁和动态启用减少运动都会清理帧并落到有效宽度。
- 新增7项有界事件/逐帧检查。侧栏与导航共28项通过、0失败、0跳过；报告为`../engineering/DEV-010-sidebar-targeted.tap`。本次未重跑全量，DEV-009的487通过/1跳过继续归属该历史版本，不叠加为本轮数量。
- 合成浏览器实际双击“搭建台”导航验证收起/展开：动效中侧栏width与正文contentLeft相等，观测到253.9375与80.078125等中间宽度；最终展开准确落到254。按钮展开末段连续采样两者始终相等；边界双击恢复默认宽度时观测253.640625，结束后为254且动画标志关闭。
- [静态验收截图](../engineering/DEV-010-sidebar-settled.png)展示254宽度下侧栏与正文对齐；截图本身不证明动态过程，动态过程以上述浏览器观测和逐帧检查为依据。系统减少动态效果使用模拟媒体查询验证，未更改用户系统设置。
