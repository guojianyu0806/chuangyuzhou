# DEV-016：流动梦境与旧念头重现

日期：2026-10-12。原始用户表达单独保存在 `raw/DEV-016-user.txt`。

## 需求与设计

用户希望在创作停滞时进入梦境，让以前记录的念头自然浮现，帮助产生新的联想。现有梦境仅在分页网格上小幅漂浮，不能表达持续流动及记忆重新涌现的过程。

AI提出的实现方案：取消梦境中的规则网格和手动分页，采用有限数量的错落念头与缓慢流动的背景；一条主念头轮流靠近，其余碎片在周围漂移。随机轮次覆盖全部符合搜索条件的未归档记录，同一轮不重复主念头，不生成或冒充用户记录。阅读停留、键盘焦点、详情打开、后台页面及减少动态效果时停止自动轮换。保留手动换条、搜索、查看全文、编辑、附件、归档、全屏及返回灵感墙。新联想仍由用户显式保存。

色彩沿用夜空底色 #101831、雾蓝 #9EBED7、月白 #EDF0FF、浅紫 #C2AAFF 与记录自身色彩；中心念头采用本机楷体候选作为展示文字，控制文字沿用工作台字体。视觉重点是念头在柔和雾光中浮现，避免所有云朵同时高速移动、闪烁或覆盖正文。自动浮现约每十二秒一次，入场缓慢收拢；触摸与键盘均可抓住念头。

## 同轮澄清与设计修正

最初实现了随机轮次和主念头轮播，工程逻辑及合成页面已经检查，但用户随后明确指出这仍过于接近重新打乱。该方案未作为完成版本交付；“约每十二秒一次”的固定主卡设计被撤回。

据追加需求调整为：所有未归档真实记录组成完整候选池，每次独立随机选择，近期出现过的记录降温，较少出现的记录提高机会；不设分页、固定中心和强制轮次。每隔随机的3—6.5秒尝试让一两条念头出现，位置、尺寸和18—34秒的停留时长分别变化；每条独立淡入、漂移和散去，其他念头不整体重绘。屏幕同时最多3—5条，空间不足则等待空位，避免把“全部可参与”误做成“所有文字同时挤在屏幕”。手动“让灵感涌来”可主动唤起记录。此为AI提出的具体实现节奏，非用户指定数值。

## 验收计划

轮播覆盖与防立即重复；空集合、单条及大量记录；搜索与归档过滤；暂停、悬停、焦点、可见性与卸载清理；详情开关及编辑/附件/归档保留；桌面和窄内容宽度的阅读与操作。按真实执行情况补充结果，不将计划或代码检查写成实测。
