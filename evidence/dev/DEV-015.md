# DEV-015：独立灵感墙与自然错落的卡片

日期：2026-10-09。根据原始用户需求整理，原文单独保存在 `raw/DEV-015-user.txt`。

## 目标与设计

用户希望灵感区域的卡片排列区别于其他业务，更能表达想法迸发的感觉。只更新比赛 `yuzhou/` 复制件，原宇宙、原创宇宙和旧app保持原样。

AI提出并采用的方案：默认灵感墙采用自然错落的纸片、便笺和对话气泡；内容长短影响文字尺寸与卡片高度，分类决定轻微的形状差别，稳定倾角避免每次重绘随机跳动。粉彩色延续工作台，短暂入场与悬停扶正作为主要动效，不持续漂浮、不以装饰线条伪造资料关联。标题少量使用本机楷体候选，正文沿用现有字体，无外部字体或图片依赖。

色彩基准：薰衣草 #C7B3F5、薄荷 #B7DED0、浅莓 #EBC0CC、嫩黄 #DAE394、深墨 #37304B；卡片优先沿用用户已有颜色，并混入白色以保证文字对比度。

布局草图：

```text

搜索                    灵感墙 / 自由画布 / 梦境
分类筛选与真实条数
  纸片          气泡        短便笺
  长想法                    摘录
                便笺        纸片
```

保留旧自由画布与梦境模式、原手动坐标、正文编辑、附件、标签、分类、转待办、归档和恢复。切换视图不迁移或删除记录；窄屏转为单列，并支持键盘与减少动态效果。仅使用真实已有记录，不自动填充虚构灵感或调用模型。测试演示另用独立合成实例。

## 验收计划

核对搜索及分类、长文本与空态、视图切换及旧布局保留；验证编辑、转待办防重复、归档恢复；检查桌面／窄屏、键盘焦点及减少动态效果。先做针对性工程检查，再做合成浏览器验证，保留真实失败与修复，不把外观检查写成AI效果。

## 实施结果

新建inspiration.js与inspiration.css，只有收集箱使用专属灵感墙，未修改通用mountCanvas或其他业务卡片外观。按稳定ID决定轻倾斜，按正文长度区别短句和长文，按分类选择纸片／柔角便笺／摘录气泡；原有记录及旧画布颜色优先。按时间倒序展示，搜索不改排序源数组、不写业务状态。现有ui.inboxView的cards／未配置默认进入新墙，canvas明确进入原自由画布，dream保留梦境；备份及AI偏好设置接受三个值。

内容容器宽度620像素起两列、900像素起三列，更窄时单列；标题与操作随宽度换行。增加常驻搜索、分类、编辑、附件、变成行动／查看待办、归档／恢复按钮。新墙可准备AI整理对话，仍须主动发送和审核方案。进入动画有界，搜索期间不重复播放；减少动态效果规则取消动画和过渡。

## 真实问题与迭代

- 浏览器首轮发现转待办已经增加记录，但灵感卡片仍显示“变成行动”。原因是既有插入函数只更新导航计数，新墙持有旧关联集合。现已在创建成功后重绘，立即变为“查看待办”；再次点击打开同一待办，不再新增。
- 初版在常见桌面内容区仅两列，卡片过宽；通过截图复核把三列断点从1100调整为900，并让较窄标题行主动换行。未改变正文或记录顺序。
- 新测试首跑1项失败是断言同时比较了未知分类与备忘的形状和颜色，超出“颜色回退”目标。收窄为颜色语义后7项通过，产品代码未为错误断言改变。真实失败输出保留在开发对话。
