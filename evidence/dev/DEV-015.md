# DEV-015：独立灵感墙与自然错落的卡片

日期：2026-10-09。根据原始用户需求整理，原文单独保存在 `raw/DEV-015-user.txt`。

## 目标与设计

用户希望灵感区域的卡片排列区别于其他业务，更能表达想法迸发的感觉。只更新比赛 `yuzhou/` 复制件，原宇宙、原创宇宙和旧app保持原样。

AI提出并采用的方案：默认灵感墙采用自然错落的纸片、便笺和对话气泡；内容长短影响文字尺寸与卡片高度，分类决定轻微的形状差别，稳定倾角避免每次重绘随机跳动。粉彩色延续工作台，短暂入场与悬停扶正作为主要动效，不持续漂浮、不以装饰线条伪造资料关联。标题少量使用本机楷体候选，正文沿用现有字体，无外部字体或图片依赖。

色彩基准：薰衣草 #C7B3F5、薄荷 #B7DED0、浅莓 #EBC0CC、嫩黄 #DAE394、深墨 #37304B；卡片优先沿用用户已有颜色，并混入白色以保证文字对比度。

保留旧自由画布与梦境模式、原手动坐标、正文编辑、附件、标签、分类、转待办、归档和恢复。切换视图不迁移或删除记录；窄屏转为单列，并支持键盘与减少动态效果。仅使用真实已有记录，不自动填充虚构灵感或调用模型。测试演示另用独立合成实例。

## 验收计划

核对搜索及分类、长文本与空态、视图切换及旧布局保留；验证编辑、转待办防重复、归档恢复；检查桌面／窄屏、键盘焦点及减少动态效果。先做针对性工程检查，再做合成浏览器验证，保留真实失败与修复，不把外观检查写成AI效果。
