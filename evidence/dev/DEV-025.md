# DEV-025：入口卡片持续自主漂浮

日期：2026-10-15。用户原文单独保留于 `raw/DEV-025-user.txt`。

在现有双形式入口中增强无需鼠标参与的自主漂浮：各张卡片以不同周期、相位、方向持续横向游移、上下起伏并轻微摆动，中央入口保持较低幅度。形式1与形式2及中间态共用浮动层，紧凑排列时收敛幅度；鼠标视差、局部悬停稳定、全场暂停、减少动态效果、后台和离屏暂停、点击导航继续保留。

修改范围仅为本比赛 `yuzhou/` 复制件和配套记录；不保存原画布坐标或业务内容，不修改原项目和旧 app，不调用模型。按需求记录、源码及验证记录分阶段提交。参考链接为用户指定的 https://www.lightspark.com/?ref=land-book.com ，只观察视觉与运动，不复制站点素材。

初步核查：已有 CSS 自主动画的周边位移仅为 `(0,-7px)` 至 `(5,8px)`、周期7—11秒；中央上下幅度4px、周期11秒。布局、鼠标响应和自主动画分别位于不同层，未发现无条件关闭动画的覆盖规则。因此本轮以可感知的漂浮增强为目标，不预先宣称修复了导致用户页面静止的确定故障。系统减少动态效果仍须尊重。

## 实施结果

- 自主运动继续由 CSS 驱动：横向独立 `translate`、纵向及倾角 `transform` 分别使用不同周期，周边卡片再区分相位、幅度和横向符号，形成持续游移。保留布局外层、鼠标响应中层、漂浮内层的分工，未增加持续运行的 JavaScript 动画循环。
- 周边横向基础幅度4—12px、纵向7—18px随视口变化，再乘单卡系数；中央为横向5px、纵向8px和较轻的倾角。形式进度从0到1时幅度系数由1线性降低到0.45，不重置动画时钟。
- 继续保留暂停、悬停／聚焦／按住当前卡片的保护、后台／离屏／减少动态效果规则。未添加页面缩放控件或拦截浏览器快捷键；原生缩放映射没有改动。
- 需求记录提交 `037b06d`，源码、3项回归和独立合成启动器提交 `60301bb`。没有 push、发布或提交比赛。

参考站已打开并看到首屏卡片环绕中央内容、前后层次及留白；读取页面和连续截图多次超时，未稳定测得原站运动轨迹、周期或速度。本轮参数为针对工作台入口设计的实现，不宣称逐帧复刻，也未复制其图片、代码或品牌资产。最初使用对称关键帧的 reverse 并不会产生有效方向差异，复核后改成横向幅度的正负交替；该修订已包含在源码提交和全量检查中。
