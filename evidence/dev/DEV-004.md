# DEV-004：以 AI 伙伴为核心的工作台搭建平台

日期：2026-10-09。本文根据原始对话整理，不替代原始 Prompt。用户确认把个人定制工作台转为可自行搭建的平台，并授权在当前基础上修改；原始指令另存 `raw/DEV-004-user.txt`。

## 目标与当前问题

使用者可以从空白或模板起步，选择模块、创建空间并调整自己的布局。平台提供材料、规则和指引，AI 伙伴理解工作台上下文，通过审核方案帮助搭建和跨模块操作。现有完整宇宙保留为可选模板和示例。

现状：课程、六级等个人用途固定出现在所有人的导航和首页；新用户没有选择模块的起步流程。自由画布、空间、业务操作与 AI 审核已经存在，本轮复用这些能力，不宣称为重新开发的成果。

## 本轮实施方案（AI 提出）

1. 新增独立工作台配置及模块目录、场景模板。新用户从空白引导起步；没有该字段的旧数据兼容完整宇宙，不能按记录数量猜测是否新用户。
2. 新增搭建台，支持命名、模块启用/收起、重命名、顺序和模板预览。收起只改变展示，记录和已有画布坐标保留；原业务及自建空间继续可用。
3. 导航与首页读取配置。AI 始终可达，以常驻伙伴入口提供搭建、整理和操作入口；助手草稿经用户发送才调用模型。
4. 扩展原 AI 白名单动作，支持工作台命名、模块配置和顺序；复用原空间创建修改及画布排布动作。保留预览、确认、版本保护和撤销；不宣称任意系统操作。
5. 同时更新存储、备份和上下文校验，防止旧客户端或导入过程静默丢失新配置。工程与浏览器仅使用合成数据，不读取正式凭据、用户私有资料或调用收费模型。

## 验收条件

- 新用户可选择模板或空白搭建，已有宇宙数据不会被清空。
- 模块名、顺序、显示状态在导航及首页一致，刷新后保留；隐藏再恢复不丢记录和布局。
- 自建空间继续保存原业务数据，AI 可读取平台配置并形成可核查行动。
- AI 方案未确认不修改业务；确认后配置生效；撤销保护后续手动修改。
- 原项目、旧 `app/` 不变；真实模型质量仍待专用 Key 及额度验证。

实施结果、真实失败与 Git 索引按实际过程补充。
