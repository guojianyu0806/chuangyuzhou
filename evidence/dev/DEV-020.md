# DEV-020：自由画布卡片内容随尺寸适配

日期：2026-10-13。原始请求另存 `raw/DEV-020-user.txt`。

## 需求与方案

用户观察到首页自由画布中放大生活回顾卡片后，内部柱图与文字仍保持原尺寸，希望图形随卡片大小自适应。当前插画采用固定像素，正文上下锚点仅扩大空白。

本轮直接调整比赛 `yuzhou/` 复制件：首页自由画布根据卡片宽高共同调整插画、标题、统计和留白。装饰图形等比缩放，保留阴影与层次；紧凑尺寸避免图文遮挡。AI表单保持真实可操作尺寸，不整体拉伸。列表、网格和堆叠保持既有显示，不更改记录或已保存的方块几何。

计划验证生活回顾、课程、灵感、英语、自建空间及自定义方块的大/小/扁/窄尺寸，操作入口、设置尺寸保存与刷新、其他排列模式及AI输入。合成实例中验证，不修改正式账号布局或读取凭据、私人数据库，不调用模型。代码与证据只在比赛目录内，旧app与原项目保持原样。
