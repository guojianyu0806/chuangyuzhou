# DEV-011：侧栏拖动结束后清除整高高亮

日期：2026-10-09。根据用户原始需求整理，原文见`raw/DEV-011-user.txt`。

问题：侧栏拖动时程序主动聚焦拖柄，松开后保留焦点外框；鼠标仍悬停时，整高紫色线也不会消失。

修改：只在真实指针手势结束或取消时释放拖柄焦点；整高高亮仅用于拖动和键盘焦点。悬停只提示中央短抓手，取消整高线150毫秒渐隐，松开立即清除。键盘操作和DEV-010弹性动效保留。

验证：已有侧栏/导航28项针对检查通过，未重跑全量。4398新建合成账号浏览器实际拖动80→220，松开后focused=false、outline=none、整高线透明、dragging=false；鼠标仍hover也无整高线。随后键盘ArrowRight得到240并显示键盘焦点提示。静态截图见`../engineering/DEV-011-sidebar-release.png`。未使用模型或正式私人数据。

只修改比赛复制件的`sidebar-resize.js`和`shell.css`，原项目、旧app和旧证据保留。本记录、原始需求及截图为新文件，未覆盖旧交付物。真实本地修复提交见Git历史，未push。
