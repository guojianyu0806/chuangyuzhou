# DEV-029 · 日常使用整理与提交材料核查

日期：2026-10-16。用户授权检查比赛提交缺口，并将比赛副本界面与起始内容整理为可日常使用的环境。该授权允许在正常登录的正式 4397 账号操作，替代前阶段仅合成账号的业务范围；不扩大至原项目、数据库直写、凭据读取、远程发布或比赛提交。

## 实施

- 界面标题、侧栏、登录、设置、连接、保存与解析说明改为正常产品文字。仅改展示文案，不变更实例身份、端口、鉴权或独立存储。
- 移除搭建台批量导入项目示例、全模块示例及导览入口；原生成器作为历史来源和合成测试夹具保留，不自动注入新账号。模块、场景模板、AI、空间和自定义方块功能保留。
- 新增显式的“模板与更多设置 → 起始资料整理 → 预览整理”。只处理既有起始资料编号、上一轮新增的两个筹备空间及带原始特定标记的三条创作想法，不遍历修改任意个人正文或小程序源码。
- 预览不写入；确认时校验原始内容没有变化，失败恢复原状态。离开搭建台前支持撤销，后续内容变化时拒绝覆盖。笔记旧文保留修订，来源标记不清除。画布、导航、AI 草稿与模型配置不参与迁移。
- 经当前账号正常界面预览，保存 72 项整理并观察到“已同步”；刷新后保留。2 条预填支出、4 条预填运动、1 条预填完成记录归档；进度 2/5 改为 0/5。计划与草稿继续可编辑，不改写为实际完成、实际消费或真实活动成果。
- 课程页剩余示例筛选／徽标改为学习资料与参考文案；回顾页的来源提示只根据已展示的完成／学习记录判断，普通课程或想法不再触发“含起始占位记录”。历史归档账目仍说明未实际发生，不伪造财务事实。
