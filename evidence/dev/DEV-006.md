# DEV-006：搭建画布缩放与平移

日期：2026-10-09。根据本轮原始需求整理，原始摘录保存在 `raw/DEV-006-user.txt`。用户认可当前可视化摆放形式，要求像首页一样放大、缩小和拖动整个画布。

## 本轮方案与验收

沿用已有搭建台和方块交互，增加缩放按钮、比例显示与100%复位，支持画布空白拖动、空格配合拖动及鼠标中键平移，并延续首页的滚轮习惯。缩放以可见中心或指针位置为锚点，网格、方块与待放轮廓使用同一坐标变换。

视野变化仅保存在本次搭建页面会话，不修改方块世界坐标、不写业务状态、不使AI方案失效。拖动画布不能误触放置；缩放平移后的新建、移动、取消及撤销须保持正确。从新访问或显式“看全画布”可重新定位。只使用本项目合成数据验证，不调用真实模型，不改原项目和旧app。

以上为根据目标提出的实现方案，不把具体设计细节当作用户原始Prompt。

## 已实施

- `placement-camera.js` 提供不可变视野变换与有限数值校验。比例范围0.1%—160%，兼容大量或远距离卡片的初始全局视图。缩放维持中心或指针锚点下的世界位置，平移用屏幕增量换算。
- `placement.js` 接入减号、加号、比例复位、空白处拖动、空格拖动及中键平移；普通滚轮平移，Shift改变轴向，Ctrl/Meta滚轮缩放。画布获得焦点时方向键平移，+/-/0调整视野；已选待放方块继续使用方向键和回车放置。
- 相机仅在搭建页面会话中保留，不调用保存接口、不改业务或方块坐标，不改变AI上下文指纹。网格、方块和半透明落点统一变换；缩放后放置和撤销保留既有原子保存、冲突校验与业务数据保护。
- “看全画布”、重新进入或尺寸变化可重新适应范围。比例复位是恢复100%大小，保留可见中心；查看范围与实际摆放位置分别管理。
- `placement.css` 增加拖动手势提示和可换行的缩放控件，小屏控件维持至少44像素高度。

## 实际问题与迭代

1. 浏览器快速从背景平移切到方块库时，原350毫秒点击抑制挡住新选择。改为平移后的抑制只针对舞台尾随点击，显式新选择正常接入；新增事件回归覆盖待放→平移→尾随点击不放下→立刻换选。
2. 独立审查发现第二指的移动可能进入第一指的预览分支。补齐指针身份判断；该保护通过事件测试，不声称实机多指手势已验证。
3. 100%复位或滚轮移动后仍保留“已显示全部方块”的旧提示。改为与当前缩放和平移状态一致的反馈，不改变坐标算法。
