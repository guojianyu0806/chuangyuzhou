# DEV-024：双形式连续变形与中央浮动卡片

日期：2026-10-13。原始需求见`raw/DEV-024-user.txt`。

用户明确区分形式1（錯落悬浮、适当填空、可点击）与形式2（DEV-023较紧凑网格），要求二者并存而非互相替换。中间工作台入口也改为实体浮动卡片；缩放时连续线性改变位置、尺寸与角度，允许停留中间状态。双击空白或中央卡非交互区域时，中间值先到较近端点，端点双击则切换另一端；两端正中间统一向形式2。外围卡点击和中央进入继续导航，双击业务按钮不作为布局切换。

设计沿用现有纸白底、真实卡片颜色、中文标题和柔和阴影；形式1采用不规则位置、不同尺寸及倾角，形式2保留连续铺排。中央卡片使用浅色半透明面板、圆角与独立低幅浮动。几何插值和自主漂浮分层，显式形式切换以常速线性过渡，可从当前视觉进度中断；减少动态效果直接落位。

输入默认方案（已向用户提供可选澄清，收到回复再按实际选择调整）：页面内滚轮/触控板与＋／－控制，放大趋向形式1、缩小趋向形式2。另提供形式端点和连续比例条。窄屏普通滚轮保留纵向滚动；缩放手势及显式按钮仍可控制形式，不接管浏览器Ctrl键盘快捷键。

实现与验证范围限比赛yuzhou副本，不更改原宇宙、原创宇宙、旧app、正式业务数据或旧交付物。几何、控制器、样式和集成分工实施；计划验证两端/中点线性几何、双击规则、输入中断、布局无横向溢出、中央卡与原点击入口、减少动态效果和卸载。本轮不发送模型请求。
