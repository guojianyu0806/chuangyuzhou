# DEV-023：迎接页紧凑排布与方块直达

日期：2026-10-13。原始需求见`raw/DEV-023-user.txt`。

用户认可DEV-022的悬浮形式，要求减少外围空旷区域，并能从卡片直接进入对应内容。本轮仅修改本比赛yuzhou复制件；保留中央进入、独立漂浮、鼠标分层运动、原画布及账号数据。

设计计划：沿用纸白#F8F9FB、墨色#242137、紫#7851D9，以及真实方块蓝#9DC5FF、青#63E6DC、粉#FF9CCE。标题继续系统中文粗体，正文与数量使用现有系统无衬线。将外围10个稀疏绝对落点改为最多20个紧凑格位，在中央入口周围连续铺排，卡片仍有不同角度与浮动相位。桌面六列留中央2×2入口区，较窄屏幕顺序换行，手机保留完整可点卡片并正常纵向滚动；不通过复制虚假卡片填满空间。

卡片使用原生按钮，支持点击及键盘进入真实模块、空间或自定义块；从受控目录取route/subroute，不信任DOM随意提供的目标。鼠标悬停、键盘焦点或按住一张卡片时，仅本张保持位置，保证点击稳定；其他卡片继续浮动。保留暂停、减少动态效果、后台/离屏停止与离开清理，不自动发送AI请求或运行小程序。

计划验收：模块/空间/自定义块三类点击、键盘进入、悬停锁定与其他卡片继续、迟到/伪造目标拒绝；桌面中央入口无阻挡、窄屏无横向溢出、全部渲染卡片可达；现有暂停与路由回归。仅用隔离合成账号验证，阶段结果另行追加。

## 实现与过程

源码提交`88d662c`。选卡上限从10调整为20，已启用内置模块优先，包含至少一个已有空间与自定义块，其余按目录顺序补齐，不重复或伪造记录。桌面由固定外围坐标改为六列四排，中央保留2×2格；601—1099像素使用四列六排，600及以下使用两列和正常纵向滚动，全部已渲染卡片保持可见。保留真实配色、图形、半透明层、阴影和不同角度/相位。原数据池超过20张时仍从中央进入完整画布；若实际内容不足，不伪造卡片补空。

上一版卡片为`aria-hidden`装饰且关闭指针事件，确实不能点击。现改成有明确名称的原生按钮；DOM只提供卡片ID，挂载时记住实际展示集合，点击时再查询当前合法目录取route/subroute。现有`ctx.go`统一编码ID，中文、斜杠、百分号和`block:`只编码一次；已收起/归档、未知、未展示或过期视图的目标不能从迟到按钮导航。入口只跳转，不保存业务、不调用AI或执行小程序。

鼠标进入、键盘聚焦或按下卡片时，`welcome-card-held`冻结本卡的CSS漂浮与JS响应当前位置；其余卡片继续。内部元素切换不误解锁，真正离开平滑续动；触摸取消与窗口失焦释放按下状态。没有preventDefault或指针捕获，不劫持滚动。暂停、减少动态效果、隐藏/离屏和卸载仍使用原边界。

视觉联调先发现最小舞台高度带来16像素整页滚动，已从580调整为560像素；最终桌面1280×720页面高720。验证脚本曾在hash改变/刷新后DOM尚未渲染时读到0卡或空节点，改为等待真实目标出现后读取；最终原画布22卡已确认。这属于验收读取时机，未当作应用缺陷修复。
