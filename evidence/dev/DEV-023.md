# DEV-023：迎接页紧凑排布与方块直达

日期：2026-10-13。原始需求见`raw/DEV-023-user.txt`。

用户认可DEV-022的悬浮形式，要求减少外围空旷区域，并能从卡片直接进入对应内容。本轮仅修改本比赛yuzhou复制件；保留中央进入、独立漂浮、鼠标分层运动、原画布及账号数据。

设计计划：沿用纸白#F8F9FB、墨色#242137、紫#7851D9，以及真实方块蓝#9DC5FF、青#63E6DC、粉#FF9CCE。标题继续系统中文粗体，正文与数量使用现有系统无衬线。将外围10个稀疏绝对落点改为最多20个紧凑格位，在中央入口周围连续铺排，卡片仍有不同角度与浮动相位。桌面六列留中央2×2入口区，较窄屏幕顺序换行，手机保留完整可点卡片并正常纵向滚动；不通过复制虚假卡片填满空间。

卡片使用原生按钮，支持点击及键盘进入真实模块、空间或自定义块；从受控目录取route/subroute，不信任DOM随意提供的目标。鼠标悬停、键盘焦点或按住一张卡片时，仅本张保持位置，保证点击稳定；其他卡片继续浮动。保留暂停、减少动态效果、后台/离屏停止与离开清理，不自动发送AI请求或运行小程序。

计划验收：模块/空间/自定义块三类点击、键盘进入、悬停锁定与其他卡片继续、迟到/伪造目标拒绝；桌面中央入口无阻挡、窄屏无横向溢出、全部渲染卡片可达；现有暂停与路由回归。仅用隔离合成账号验证，阶段结果另行追加。
