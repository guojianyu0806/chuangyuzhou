# DEV-005：直接摆放工作台方块

日期：2026-10-09。根据本轮原始需求整理，原始摘录另存 `raw/DEV-005-user.txt`。用户反馈现有放置方式抽象，希望更直观；本轮直接改进当前比赛副本的交互。

## 目标与方案

现有搭建台把选择模块、调整导航顺序与实际画布位置分开，用户难以预判摆放结果。新增同屏方块库和可操作画布：可先选方块再点落点，也可拖动放置；显示待落下的方块、明确的选中和保存反馈，并可撤销最近一次摆放。模板、模块管理和AI入口继续保留。

这是AI提出并依照用户目标实施的具体方案，不是用户逐字指定的技术实现。可视摆放读写现有 `state.canvas.cards`，避免独立示意图与真正工作台不一致。纯预览、移动指针或取消不得改状态；显式放置才保存。保存失败回滚配置和布局，撤销不得覆盖后续修改。原项目及旧app继续保留。

## 验收范围

- 方块和落点在同一画面可见，点选放置与拖动两种路径均有提示。
- 实際保存坐标在重新加载及进入工作台后保留；原有隐藏模块坐标和业务数据不丢失。
- 新增、移动、取消、保存失败和撤销有相应保护；触控和键盘有可行入口。
- 仅合成实例验证，不读取正式用户内容或调用真实模型。

## 实际实现

- `placement-model.js` 在独立副本内复用现有画布坐标。读取预览不初始化或修改工作区；显式放下才启用模块并保存位置，不覆盖其他卡片尺寸、颜色和业务记录。
- `placement.js`、`placement.css` 提供同屏方块库、真实比例缩略画布、点击放置和指针拖放、半透明落点、40单位网格、方向键微调、回车放下及Escape取消。
- 保存失败回滚，撤销最近一次操作前先比较配置和布局，拒绝覆盖后续人工或AI修改；撤销只恢复布局配置，保留后来添加的业务记录。撤销记录仅在当前搭建台页面会话有效，离开或刷新后不保留。
- 模板、改名、显隐和自定义空间管理仍在“模板与更多设置”；AI搭建入口及小宇继续保留。本轮新增交互不自动请求模型。
- 从搭建台进入工作台时适应全部真实卡片，首页直接使用同一组坐标。手动放置后不自动移动或缩放搭建视野；“看全画布”和窗口尺寸改变时重新适应。

## 真实问题与修复

1. 浏览器拖动后发现自动适应范围会改变缩放，造成松手后方块偏移。改为保存当前会话视野，显式适应或窗口变化时才重新计算。搭建页关闭会改变指针坐标的入场缩放动画。
2. 独立复核指出“整齐排列”撤销可能恢复到新视野以外。现同时保留操作前视野；浏览器比对撤销前后卡片屏幕样式一致。
3. 连续自动化操作发现拖动后350毫秒点击抑制会影响工具栏。工具栏不再受该抑制影响；保留防止拖动结束误触的卡片保护。另加单活动指针保护，多指硬件未实测。
4. 第一版截图中小卡片描述挤压标题，实际出现标题纵向裁切。紧凑卡片收起描述且标题不参与收缩。旧截图 `DEV-005-visual-placement.png` 保留；最终复核截图另存 `DEV-005-visual-placement-verified.png`，不覆盖旧成品。
