# DEV-021：在搭建台管理侧栏导航

日期：2026-10-13。原始需求见`raw/DEV-021-user.txt`。

## 需求与实施计划

用户希望在搭建台控制侧栏导航的排列顺序，以及直接显示和折叠显示的入口。增加独立的导航配置，让已启用模块和未归档项目空间可以排序，并选择直接显示、收进“更多导航”或不在侧栏显示。工作台与搭建台保留直接入口，避免设置后失去返回和恢复的路径。

导航调整不等同于移除方块；画布位置、模块启用情况和业务记录保持。旧工作台无此配置时沿用原顺序，新加入的模块与空间自动补入，恢复默认仅清除导航偏好。保留侧栏宽度、弹性切换、移动抽屉及原有计数和路由行为。

仅修改本比赛`yuzhou/`复制件。在合成实例验证排序、折叠、隐藏、恢复、刷新保存和业务保留，补充配置/回滚/交互测试；不读取正式数据库或凭据、不调用模型、不修改原项目或旧app。实现与验收分阶段提交，不预先将计划记为通过。

## 实际实现

- `workbench.navigation`是可选的有序配置，入口按稳定ID引用已启用模块、未归档空间及两个基础入口。缺失时沿用原顺序；停用、归档或暂时不存在的入口偏好保留，新入口默认直接显示。配置有数量、字段、ID、重复和固定入口校验，备份、模板及既有AI模块行动保留此配置。
- 搭建台在AI引导下方增加可展开的“侧栏导航”。支持真实指针拖动、跨组落点、上下按钮、位置选择、效果预览和恢复默认。只重绘设置面板，保留焦点、滚动和展开状态；保存失败回滚，过期工作台禁止写入，拖动中不提前保存，取消及卸载清理。
- 侧栏按设置渲染直接显示与原生details折叠区，隐藏入口不影响首页方块。模块待办/收集箱计数保留，项目空间拥有独立当前项标记；进入折叠区中的当前路径会展开，普通保存不强制重新打开用户收起的分组。80像素栏保留“更多导航”图标与文字提示。底部工具不参与此排序。
- 没有新增AI导航行动，也未把人工导航编辑描述为真实模型能力；既有AI模块修改/撤销继续保留导航偏好并校验冲突。
