# 宇宙 · 传智杯独立副本（基于 0.15.0）

本目录是从桌面宇宙完整复制后独立适配的前端，使用原生 HTML、CSS、JavaScript ESM，无第三方前端运行依赖。保留原有课程、课表、账本、健身、自建空间、日历、比赛、六级、AI 对话与资料管理界面。原项目和此前 `app/` 副本未被修改。

以下旧版本记录用于说明继承来源，不代表本比赛新增成果。当前业务源码版本为 0.15.0，比赛隔离改动由本项目 Git 历史记录。

0.10.0 记账分为日常零钱、项目账本和总账单。项目可设置「计入总账单」：旧项目缺省保持计入，新项目默认独立核算；设置作用于该项目全部历史收入和支出，日常零钱始终仅包含未分项目的账目。项目卡片显示累计收支，进入项目默认全部日期；主页记账卡片遵循总账口径。设置纳入云同步、备份与旧客户端丢字段保护。手机 AI 页压缩工具与历史区，扩大对话可视区域。

0.9.1 AI 收件台增加明确的「对话沟通 → 审核方案 → 确认执行」流程。审核单用与实际写入相同的逻辑生成，逐项展示内容、实际保存位置、附件、待办日期与优先级；确认后显示执行清单。继续发送消息使旧方案失效，未发送的草稿、附件或归属修改阻止执行。聊天内说确认不会触发工作区写入。

0.9.0 新增独立日历：月历与日程列表，按日期记录计划、标注和注意事项；支持全天、指定时间、跨天、地点、备注、重要标记、完成与归档恢复。日历独立于学期课表，不自动把课程写入日历；纳入现有私人云同步和完整备份。主页卡片与侧边栏均有入口，手机可从「更多」进入。

0.3.0 新增记账：收入与支出、按日期筛选、按项目汇总、自建项目、编辑与归档恢复。金额使用人民币，以整数分保存；账本包含在原有完整备份和私人云同步中。

0.2.1 统一使用“宇宙”品牌与轨道图标；网页标题、安装名称、登录页及备份文件名同步更新。账号、浏览器存储标识和备份格式保持兼容，原有资料与备份可以继续使用。

## 启动

需要本项目启动器要求的 Node.js 版本，无需运行 npm install。在本目录运行：

```powershell
node server.mjs
```

也可以运行 npm start 或双击 start.cmd。三种方式均委托 ../start.mjs 启动本比赛完整后端，仅监听本机 http://127.0.0.1:4397 。保持终端打开；Ctrl+C 停止。启动器不自动打开浏览器，不复用原工作台端口或原服务，也不继承旧 HOST、PORT、数据路径和密钥。

首次使用需为本比赛实例新建账号与至少 12 位字符密码。初始化口令及运行路径见上层启动说明。不要向聊天提供口令或 API Key。

## 已实现的界面和操作

- 空间主页：标题、视图切换与常用操作在宽屏合并为紧凑的一行，窄屏分两行并保留大触摸按钮；自由画布自动使用窗口剩余高度。亮色霓虹卡片支持平移和缩放；长按卡片约半秒，轻弹浮起后拖动摆放，松手保存。短按进入空间有推进转场；拖右下角改大小、菜单换颜色，也可直接拖手柄。小屏默认卡片列表，可切换自由画布。
- 动态侧栏：电脑悬停展开、移开收起，可固定展开；手机使用抽屉导航和底部快捷入口。
- 自建工作区：自由空间、课程、学生会事务、个人项目模板，自定义名称、用途、颜色和图标。每个空间包含笔记、原文件、关联待办；支持归档与恢复，笔记编辑保留修订。
- 文件拖入：可从桌面拖到工作区卡片或空间内保存原件；课程总入口会收进 AI 草稿，供选择具体课程，手机可用文件选择按钮。
- AI 收件台：主页直接输入文字或添加文件，草稿和队列保存在本机。未连接模型时明确等待；可手动选择工作区归档原文，查看回执、撤回未修改内容，已经编辑过的记录保留。
- 课程空间：使用与主页相同的霓虹画布和长按拖动，课程布局独立保存并纳入备份；搜索、筛选、拖文件到指定课程、课程创建、资料上传与下载、TXT／图片／PDF 预览、笔记编辑、旧版修订记录、Markdown 导出及课程助教偏好。
- 内页卡片：课程笔记/资料、自建空间总览/笔记/文件/待办、全局待办与灵感均采用独立自由画布，支持长按轻弹后移动、改颜色和尺寸；每个内页的布局纳入完整备份。阅读和编辑保持独立卡片，六级、AI、回顾及设置页统一使用明确的彩色分区。
- 六级计划：目标设置、词汇卡片、原创阅读练习及本地判分、错题本、听力音频、写作／翻译草稿、学习时长记录和归入六级的资料。
- 收集箱：文字、链接、消息摘录、附件、分类、归档及转为待办。
- 备忘与待办：新增、编辑、完成、日期安排、分类、优先级、归档与恢复。
- 学习回顾：根据当前空间的实际记录统计完成事项、笔记和学习时长。
- 偏好与连接：个人资料、模型服务偏好、连接状态、完整备份导入导出、窗口冲突恢复副本、版本检查。
- 全局搜索：按 `Ctrl+K` 搜索自建工作区、课程、笔记、待办和碎片。

## 独立服务与 AI 状态

- 首次访问建立本比赛账号。当前仅供本机访问，未发布远程同步服务；不能将完整云同步源码的保留等同于跨设备部署完成。
- 个人空间记录、附件通过本比赛后端保存，浏览器保留独立缓存；示例模式仅在本机，不上传。约每 5 秒检查本实例变化；未保存编辑阻止自动替换。冲突时保留恢复副本。
- 设置页中的 DeepSeek Key 仅保存到本比赛实例，不写入浏览器存储或工作区备份。密钥保存、独立 AI 引擎配置、真实模型验证是不同状态。没有独立引擎时明确显示待配置；复制源码不会让原引擎或密钥自动可用。
- 原 AI 作业、文件提取和审核确认代码已保留。文字及 TXT、MD、CSV、可提取文字 PDF、PPTX、DOCX 的实际 AI 处理仍依赖独立引擎和依赖就绪。扫描图片 OCR 尚未接入。本轮隔离不触发真实模型请求。

## 数据隔离与备份

- localStorage、sessionStorage、IndexedDB、会话选择和窗口恢复缓存统一使用 czb-yuzhou- 前缀。包括迁移时读取的缓存键，也只读取本比赛前缀；不会自动发现、读取或迁移原个人工作台数据。
- 数据按浏览器、账户、模式与源隔离。localhost 与 127.0.0.1、不同端口或协议属于不同源。课表显示偏好只保存在本设备。
- 显式导入导出继续兼容原 lumi-backup 文件格式。这只是用户主动选择文件时的解析格式，不是读取旧浏览器缓存或原项目文件的入口。本轮没有导入私人资料。
- 单个附件上限 40 MB；完整 JSON 备份上限 512 MB。导出包含附件原件，缺失时会报错。导入只补充缺少的记录，已有文字保留，冲突英语草稿另存到收集箱。
- 不要清除此站点的网站数据；本机缓存和服务器数据都需独立备份。原项目的备份、配置和服务器保持原样。
