## 启动与首次使用

需要已经安装Node.js 22.13或更高版本；本地网页及基础数据服务使用Node内建模块，没有npm运行依赖。

1. 在比赛根目录双击 `启动宇宙完整副本.cmd`，或执行 `node yuzhou/launch.mjs`。电脑重启后再次运行即可；不自动创建开机启动项。
2. 启动器打开 <http://127.0.0.1:4397/>。如果本副本已运行，先验证实例身份再复用；端口被其他程序占用时提示退出，不停止对方。服务只监听本机，不发布到局域网或公网。
3. 首次自行打开 `yuzhou/.cu-runtime/data/setup-code.txt`，在初始化页面填写这份副本的口令、自选账号和至少12字符密码。口令、密码、Key无需发给AI。
4. 新账号进入搭建台，从只保留AI伙伴的空白工作台开始。从方块库选择需要的模块，再点击画布中的位置放下；也可直接拖入。顶部名称旁的编辑按钮可以修改工作台名称，展开“模板与更多设置”可先预览模板再应用。这里不包含原工作台的私人记录。
5. 点击“进入我的画布”查看实际工作台，页面会显示全部已加入的卡片。随时回到搭建台移动方块，或展开“模板与更多设置”改名、调整模块顺序、收起或恢复模块，以及新建围绕具体项目或目标的空间。

旧 `启动传智杯工作台.cmd` 及4395仍对应此前的创宇宙版本，不是本目录入口。保留首次启动服务的终端；结束该窗口会停止本副本。再次运行启动器而复用的窗口可以关闭，不会停止已有服务。也可用 `node yuzhou/start.mjs` 直接启动服务而不自动打开浏览器。原项目及其服务不受影响。

## 按自己的需要搭建

模块库有10个内置模块，AI伙伴始终可用，其余9项按需加入：课程空间、六级随身练、灵感收集箱、备忘与待办、生活回顾、记账、日历、学期课表和比赛。收起模块只隐藏入口，原有记录仍保留；重新加入后可继续使用。模块名称可更改，顺序对应导航和列表，画布位置可自由摆放。

在搭建台可以直接看见待选方块和已摆好的画布：

- 点击方块，再点击画布中的落点；或者按住方块拖入画布，按住已有方块即可移动。半透明轮廓显示预期位置，放下后才保存。
- 位置自动对齐网格。也可用方向键微调，按回车放下；按Esc或“取消选择”放弃尚未落下的预览。
- 使用画布上方的−/+按钮缩放，点击比例回到100%；拖动空白处即可平移，也可按住空格拖动或使用鼠标中键。普通滚轮平移、Shift加滚轮横向平移，Ctrl/Meta加滚轮围绕指针位置缩放。画布获得焦点时可用+/-/0缩放或复位，画布背景获得焦点时方向键平移；方块获得焦点或正在预览放置时，方向键调整方块。
- “看全画布”让全部方块回到可见范围；“整齐排列”整理当前可见方块。“撤销上次摆放”恢复最近一步，若之后的配置或画布变化产生冲突，会保留当前状态并提示，避免覆盖后续调整。撤销不会清除待办、资料等业务记录；离开搭建台或刷新后不再保留这条撤销记录。
- 模板、模块名称和显隐、导航顺序、自建空间等管理入口位于“模板与更多设置”。摆放位置直接对应首页，不需要重复配置。

缩放和平移只改变当前页面的观察视角，不修改方块真实位置或业务内容，也不会调用AI或使待确认AI方案因视图变化而失效。视图不跨页面会话保存；重新进入、点击“看全画布”或画布尺寸变化时可重新显示全部方块。

可选模板为“从空白开始”“项目推进”“研究与创作”“学习与课程”“日常生活”“完整宇宙”。应用前会列出哪些模块将加入、哪些将收起。模板只调整组合，不删除已有资料、自定义空间或画布位置，也不自动添加示例记录。需要了解完整使用形态时，可单独查看明确标注的内置示例。

已有账号如果尚无工作台配置，会保留完整宇宙的全部内置模块；不会把旧工作台重置成空白。已有业务与新平台配置沿用同一独立比赛副本的数据边界。

右下角“小宇 · AI伙伴”可以帮助准备搭建、排列和办事的对话。选择引导后只把需求放入AI草稿；你仍需主动发送，检查方案，再确认执行。当前能够调整的是已注册模块、空间、卡片及支持的业务记录，不是任意外部软件或自动生成新功能代码。宠物式形象承担常驻入口，未包含养成系统。

## AI与部署现状

DEV-004为AI补充工作台模块库、模板及当前组合上下文。新增`workbenchSettings`、`workbenchModule`行动，配合已有空间和画布行动，可以提议修改工作台名称、模块显隐、模块名称、顺序以及受支持的空间/卡片设置；所有动作继续按原有校验与确认流程执行。

在“偏好与连接”中由用户自行填写本比赛专用Key。**引擎可用、Key已保存、真实接口可达及模型效果是不同状态**：启动、查看状态、保存配置都不发起模型请求；保存成功不证明Key有效或额度充足。本轮未读取原Key、未进行真实模型调用；小样本试测还需明确额度。

资料上传、下载和正文解析独立于模型调用。课程与工作区可预览已上传资料正文；接口要求登录，解析不改变原附件、不发送给模型。TXT、MD、CSV原生解析。本机DOCX、PPTX、文本PDF使用已经存在的Codex内置Python及pypdf，只读运行比赛复制件的 `backend/extract.py`；没有安装依赖或改动外部运行时，数据和临时文件均留在本副本。

非秘密解析配置位于 `.cu-runtime/extractor-config.json`，只记录运行时路径和已探测能力，不随Git提交。换电脑时需重新核查已有Python；可在比赛根目录运行 `node scripts/configure-yuzhou-extractor.mjs --python "已安装Python的绝对路径"`，然后重启本副本。脚本不下载或安装依赖；未配置时仍可解析纯文本。修改已有不同配置须明确使用 `--replace`。OCR、扫描PDF文字识别、旧DOC/PPT不支持；混合PDF只处理可提取文字，未读到的页面会提示。

移动端和部署源码为保留参考，旧部署、打包、签名命令已禁用，未制作或安装本比赛APK，未验证跨设备部署。
