## 启动与首次使用

需要已经安装Node.js 22.13或更高版本；本地网页及基础数据服务使用Node内建模块，没有npm运行依赖。

1. 在比赛根目录双击 `启动宇宙完整副本.cmd`，或执行 `node yuzhou/launch.mjs`。电脑重启后再次运行即可；不自动创建开机启动项。
2. 启动器打开 <http://127.0.0.1:4397/>。如果本副本已运行，先验证实例身份再复用；端口被其他程序占用时提示退出，不停止对方。服务只监听本机，不发布到局域网或公网。
3. 首次自行打开 `yuzhou/.cu-runtime/data/setup-code.txt`，在初始化页面填写这份副本的口令、自选账号和至少12字符密码。口令、密码、Key无需发给AI。
4. 正常登录后先看到自己的工作区入口页。新账号点击中央“进入工作台”后进入搭建台，从只保留AI伙伴的空白工作台开始。从方块库选择需要的模块，再点击画布中的位置放下；也可直接拖入。顶部名称旁的编辑按钮可以修改工作台名称，展开“模板与更多设置”可先预览模板再应用。这里不包含原工作台的私人记录。
5. 点击“进入我的画布”查看实际工作台，页面会显示全部已加入的卡片。随时回到搭建台移动方块，或展开“模板与更多设置”改名、调整模块顺序、收起或恢复模块，以及新建围绕具体项目或目标的空间。

旧 `启动传智杯工作台.cmd` 及4395仍对应此前的创宇宙版本，不是本目录入口。保留首次启动服务的终端；结束该窗口会停止本副本。再次运行启动器而复用的窗口可以关闭，不会停止已有服务。也可用 `node yuzhou/start.mjs` 直接启动服务而不自动打开浏览器。原项目及其服务不受影响。

桌面可拖动左侧栏的右边界调宽，正文会同步让位。边界获得焦点后，可用左右键每次调整20像素、Home收起、End调到当前最大宽度、Enter切换收起与展开；双击恢复默认254像素。宽度可从80像素连续调到动态最大值（不超过380像素），中间宽度不再吸附，小幅拖动也保留；180像素只决定是否显示文字。窗口较窄时会降低上限以给正文保留约480像素。选择的宽度按本机账号和工作区记忆，刷新后保留；显式收起至80像素仍保留上次宽度偏好。单纯调宽不修改业务或画布位置，收起和展开仍使用原有界面设置。宽度不超过760像素的视口继续使用抽屉导航，不显示调宽边界。

## 从工作区入口进入

打开 <http://127.0.0.1:4397/>，或在新页面加载 `#/home`，完成既有登录后会进入 `#/welcome`。中央显示当前工作台名称与模块、空间、自定义方块数量，点击“进入工作台”打开原自由画布；未完成搭建的新账号会继续进入搭建引导。周围最多20张卡片来自当前内容，全部已启用内置模块优先，并保留空间、自定义方块的代表；数量不足时不补造卡片。点击卡片就能直接打开对应区域，也可以用Tab选中后按Enter或空格进入。完整方块仍在原画布中，位置与内容不会因入口展示而变化。

周边卡片和中央入口会独立轻轻漂浮；移动鼠标可看到分层错位与附近方块避让，中央卡的位移更轻。鼠标停在、键盘聚焦或按住一张卡片时，仅该卡片停住，方便阅读和点击；其余卡片继续，离开后平滑恢复。底部“暂停浮动”可停住全场动态，再点“继续浮动”恢复。系统开启减少动态效果时使用静态展示，页面进入后台或离屏时停止动态。中央按钮也可通过键盘聚焦并按Enter进入。

默认形式1使用不同位置、尺寸和倾角的错落布局；形式2使用整齐网格，宽屏为六列四排，601—1099像素时为四列六排，中央占两列两行。600像素及以下为两列并把中央卡放在首排之后。两种形式都按可用宽度适配，触屏与页面滚动保持正常；窄屏不会隐藏已选卡片，向下滚动可查看末尾入口，无需把全部内容挤在首屏。已收起的模块、归档或移除的空间／方块不会通过旧入口打开；侧栏单独隐藏的导航不影响仍在首页画布中的内容。

使用浏览器自带的缩放功能时，缩小页面会逐渐朝整齐形式移动，放大会朝错落形式返回；位置、尺寸和倾角在两端之间连续变化。普通调整窗口大小只重新适配卡片布局。欢迎页没有独立缩放滑杆或缩放按钮，也不接管滚轮和缩放快捷键。双击舞台空白或中央卡片内的非按钮区域，中间状态会向最近的形式归位；已经在形式1或2时，双击会切换到另一端。点击周围卡片、中央“进入工作台”或AI按钮，仍执行原来的入口操作。上述变化仅属于本次入口展示，不保存到真实画布或业务数据。

## 按自己的需要搭建

模块库有10个内置模块，AI伙伴始终可用，其余9项按需加入：课程空间、英语、灵感收集箱、备忘与待办、生活回顾、记账、日历、学期课表和比赛。收起模块只隐藏入口，原有记录仍保留；重新加入后可继续使用。模块名称可更改，模块顺序对应首页列表，画布位置可自由摆放；侧栏可在“侧栏导航”中单独安排。

在搭建台可以直接看见待选方块和已摆好的画布：

- 点击方块，再点击画布中的落点；或者按住方块拖入画布，按住已有方块即可移动。半透明轮廓显示预期位置，放下后才保存。
- 位置自动对齐网格。也可用方向键微调，按回车放下；按Esc或“取消选择”放弃尚未落下的预览。
- 使用画布上方的−/+按钮缩放，点击比例回到100%；拖动空白处即可平移，也可按住空格拖动或使用鼠标中键。普通滚轮平移、Shift加滚轮横向平移，Ctrl/Meta加滚轮围绕指针位置缩放。画布获得焦点时可用+/-/0缩放或复位，画布背景获得焦点时方向键平移；方块获得焦点或正在预览放置时，方向键调整方块。
- “看全画布”让全部方块回到可见范围；“整齐排列”整理当前可见方块。“撤销上次摆放”恢复最近一步，若之后的配置或画布变化产生冲突，会保留当前状态并提示，避免覆盖后续调整。撤销不会清除待办、资料等业务记录；离开搭建台或刷新后不再保留这条撤销记录。
- 模板、模块名称和显隐、模块顺序、自建空间等管理入口位于“模板与更多设置”；侧栏入口顺序与显示位置在“侧栏导航”中调整。摆放位置直接对应首页，不需要重复配置。

## 流动梦境

进入收集箱的“梦境模式”就会自动开始流动，无需点击唤起按钮。所有未归档灵感都有机会随机浮现，各自沿缓弯路径漂移和散去，云朵与星点柔和呼吸；只有一条记录也会持续移动。近期出现的内容会暂时降温，较少出现的旧念头也有机会回来。页面为移动预留空间，同屏只保留能读清楚的几条；搜索可以让这次梦境围绕一个词展开。

鼠标停在念头上或用键盘聚焦，只留住这一条，其余继续流动。点击展开时全场暂停，方便查看全文、编辑、下载原附件或归档；关闭详情后自动继续其他念头。顶部“暂停”可随时停住全部，“让灵感涌来”仍可额外主动唤起内容，“记下联想”保存由你输入的新想法。系统减少动态效果开启时改为静态手动体验，后台页面停止演进。它只重新呈现你的记录，不调用模型或自动生成灵感，也不改自由画布的位置。

DEV-018把漂移速度轻量提高约20%，保留原来的曲线与形式。点击“让灵感涌来”时，旧念头渐隐、新念头浮入，其他念头继续原来的运动；短时间连续点击合并成一次，不会让整片梦境反复跳变。主动暂停后仍可唤起一条，背景保持暂停。

## 创建自己的方块

搭建台提供7种类型：便签、清单、网址收藏、进度、重要日期、记录表、交互小程序。可以从空白配置开始，也可以选用14个预设：随手便笺、会议记录、每周复盘、项目检查清单、购物与出行清单、常用链接、目标进度、日期倒计时、阅读清单、内容排期、求职跟进、自定义记录表，以及计算器、专注计时器2个小工具。预设是可修改的起点，不包含原工作台私人内容。

新方块使用自己的配置与数据，可以在同一搭建画布摆放，进入方块页面编辑或使用；收起后内容保留。AI创建有两层：配置现成类型的字段和内容，或编写小程序的新交互逻辑。两者均先显示行动方案，确认后才建立或修改方块；保存代码不等于开始运行。

编辑小程序时，点击“预览草稿”试用，预览操作不会保存运行数据，可随时“停止预览”。保存后进入方块页面，点击“运行小程序”才启动；本次运行只读写该方块的数据，保存失败会提示，点击“停止”或离开页面终止运行。刷新后保留已保存数据，但需要重新点击运行。

小程序通过`app.getData()`、`await app.setData(对象)`、`app.render(组件数组)`和`app.onEvent`实现交互。生成代码在隔离Worker中执行，界面由平台支持的文字、输入、按钮、进度等组件构成，不接受任意HTML、网络访问或外部软件控制；不会获得整个工作区、账号或Key。运行器提供4秒无响应停止保护。本实例专用Key和必要模型验证授权已具备；小程序的真实AI生成质量仍须单独验证，不能由接口短测或其他业务流程推定通过。
