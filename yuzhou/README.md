## 启动与首次使用

需要已经安装Node.js 22.13或更高版本；本地网页及基础数据服务使用Node内建模块，没有npm运行依赖。

1. 在比赛根目录双击 `启动宇宙完整副本.cmd`，或执行 `node yuzhou/start.mjs`。
2. 打开 <http://127.0.0.1:4397/>。只监听本机，不发布到局域网或公网。
3. 首次自行打开 `yuzhou/.cu-runtime/data/setup-code.txt`，在初始化页面填写这份副本的口令、自选账号和至少12字符密码。口令、密码、Key无需发给AI。
4. 初始化后从空白个人空间开始，或在界面选择明确标注的内置示例。这里不包含原工作台的私人记录。

旧 `启动传智杯工作台.cmd` 及4395仍对应此前的创宇宙版本，不是本目录入口。结束当前窗口即可停止本副本；原服务不受影响。各终端关闭后需要重新启动。
